Fatal criteria: (1) Token JSON parses, (2) W3C DTCG schema, (3) semantic token refs resolve, (4) component token refs resolve, (5) WCAG contrast pairs, (6) CSS custom properties no undefined refs, (7) TypeScript compiles zero errors, (8) `npm install` + `npm run build` succeed. Warning criteria: (1) unit test failures (non-blocking), (2) hardcoded values detected, (3) interactive components missing ARIA roles, (4) quality gate score below 70/100, (5) spec↔code↔docs drift, (6) component registry incomplete, (7) one or more components marked failed
